# Submission descriptions

Each weekly Word report contains its own 200+ word submission description. Use that section when the portal asks for a report description. Read and personalize it honestly before submitting.

# Important submission notes
- The task brief says the report must be uploaded as a Word document (.doc/.docx).
- It says a GitHub URL is compulsory for technical/software tasks. This package does not create or publish a GitHub repository; create one and push the relevant files if your internship portal requires it.
- The task brief requests approximately 30–35 hours per week. The files here are structured project deliverables and reproducible demonstrations, but do not claim that a specific number of hours was actually spent.
