# Five-Week Food-Processing Cybersecurity Project

This ZIP contains one folder per weekly task. Each folder includes a Word report, code, figures, and a README.

## Weekly deliverables
1. Risk Assessment & Security Strategy Planning
2. Data Pipeline Design & Vulnerability Analysis
3. Intrusion Detection Model Development
4. Data Encryption & Privacy Preservation Analysis
5. Security Infrastructure Evaluation & Future Roadmap Proposal

## Reproducibility and honesty
- The scenario, risk scores, control maturity values, batch data, and intrusion labels are simulated.
- Week 3 metrics are generated by training the included model on the included seeded synthetic dataset.
- Week 4 code demonstrates a local AES-GCM round trip; it is not a complete production key-management design.
- No real company system was scanned, no actual breach data was analyzed, and no compliance certification is implied.
- Before submission, open every DOCX, verify that it renders correctly, run the scripts in a clean environment, and add your name/institution if required.

## Suggested execution order
Week 1: `code/risk_assessment.py`
Week 2: `code/secure_pipeline.py`
Week 3: `code/train_intrusion_model.py`
Week 4: `code/aes_gcm_demo.py`
Week 5: `code/evaluate_controls.py`

Install dependencies from each week's `requirements.txt`.
