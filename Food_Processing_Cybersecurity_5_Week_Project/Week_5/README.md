# Week 5 deliverables

## Contents
- `Week_5_*.docx`: self-contained report with methodology, findings, limitations, and a 200+ word submission description.
- `code/`: runnable Python examples and any synthetic input data used.
- `figures/`: figures embedded in the report and provided separately.
- `requirements.txt`: suggested Python dependencies.

## Important
This is an educational project using hypothetical scenarios and synthetic data. Do not describe simulated values as results from a real company, production network, or security audit. Review assumptions and rerun code before submission.

## Run
Create a virtual environment, install `requirements.txt`, then run the relevant script from its `code` directory. Some scripts expect their CSV files in the current working directory.
